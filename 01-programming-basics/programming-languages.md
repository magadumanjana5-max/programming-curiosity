# Programming Languages

## Curiosity questions

5. Who decides what a programming language can do?
   **Answer:** Its designers define the language's syntax and semantics; standards bodies, implementers, and communities may refine them. The implementation and available libraries also determine what programmers can practically do with it.
6. Why are there hundreds of programming languages?
   **Answer:** Languages are designed for different priorities: ease of learning, performance, safety, portability, or a particular domain. New languages also explore better ideas or fit new hardware and workflows; no single set of trade-offs is best for every job.
7. Why do we need Python, Java, JavaScript, C, C++, Go, Rust, etc.?
   **Answer:** They serve different ecosystems and constraints. Python is concise and widely used for automation and data work, JavaScript runs in browsers and servers, Java has a large enterprise ecosystem, C and C++ offer low-level control, Go emphasizes simple concurrent services, and Rust emphasizes memory safety with performance.
8. What makes one programming language different from another?
   **Answer:** Languages differ in syntax, type systems, memory management, concurrency model, runtime, performance characteristics, libraries, and supported platforms. These differences affect how code is written, executed, maintained, and integrated.
9. Why does a programming language need a compiler or interpreter?
   **Answer:** Processors execute machine instructions, not most human-written source code. A compiler translates source into another form before or during deployment; an interpreter or runtime executes it, often by interpreting or compiling intermediate code.
