# How Code Runs

## Curiosity questions

4. How does a computer understand `if`, `for`, `while` and `function`?
   **Answer:** A language implementation parses these words according to grammar and gives them defined behavior. It turns them into instructions or bytecode for a runtime: `if` chooses a branch, loops repeat work, and functions package reusable behavior and manage calls.
10. What actually happens when you run a program?
   **Answer:** The operating system starts a process, loads the program and its dependencies, and gives it memory and other resources. A runtime or processor executes instructions; the program may read input, perform work, communicate with other processes, and finally return an exit status or fail with an error.
