# What Is an API?

## Curiosity questions

51. What exactly is an API?
   **Answer:** An API is a defined interface through which software components request capabilities or exchange data. A web API commonly specifies endpoints, HTTP methods, input and output formats, authentication, and error behavior so clients can use a service without sharing its internal implementation.
52. Why can’t two applications simply access each other’s variables?
   **Answer:** Separate applications generally run in isolated processes, often on different machines, so their memory is not one shared address space. An API provides a controlled contract across that boundary and handles serialization, permissions, and failures.
