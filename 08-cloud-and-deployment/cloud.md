# Cloud

## Curiosity questions

96. What is cloud computing?
   **Answer:** Cloud computing rents computing resources—such as servers, storage, databases, and networking—through provider-managed infrastructure, often on demand. It can reduce the need to own hardware, but customers still configure, secure, and pay for the resources they use.
97. What is AWS/Azure actually providing?
   **Answer:** Providers such as AWS and Azure offer data-center infrastructure plus managed services for compute, storage, networking, databases, identity, and monitoring. Customers choose service levels and regions; provider responsibilities do not remove the customer's responsibility for application configuration and data security.
