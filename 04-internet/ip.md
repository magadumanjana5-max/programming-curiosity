# IP Addresses and Ports

## Curiosity questions

44. What is an IP address?
   **Answer:** An IP address identifies a network interface or endpoint for routing Internet Protocol packets. IPv4 and IPv6 use different address formats; public and private addresses have different reachability, and addresses can change.
45. Why do we need ports?
   **Answer:** An IP address gets traffic to a machine or network endpoint; a port number helps the operating system deliver transport traffic to the right service or process. Ports are part of TCP or UDP communication, not separate physical connectors.
