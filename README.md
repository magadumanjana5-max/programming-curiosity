# Programming Curiosity Challenge

The goal is to build the habit of asking: **“But how does this actually work?”**

Don’t search for answers immediately. Pick questions, discuss them with your team, make your own assumptions, and then investigate the real answer. A good programmer doesn’t just learn answers; a good programmer develops better questions.

## The seven-question habit

Whenever you learn something, ask:

**WHY? → WHAT? → HOW? → WHERE? → WHEN? → WHO? → WHAT IF?**

For example, when learning MongoDB:

- **WHAT** is MongoDB?
- **WHY** do we use it?
- **HOW** does it store data?
- **WHERE** is the data physically stored?
- **WHEN** should I choose MongoDB?
- **WHO** uses it in the industry?
- **WHAT IF** MongoDB goes down?

The answers in the guides focus on the relevant parts of this framework: what a concept is, why it exists, how it works, where it lives or is used, when it matters, who is involved, and what can happen when things change or fail. Not every lens applies equally to every question.
