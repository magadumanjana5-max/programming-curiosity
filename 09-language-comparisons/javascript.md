# JavaScript

## Curiosity questions

82. Why is JavaScript used in browsers?
   **Answer:** Browsers standardized JavaScript as a way for web pages to respond to user actions, update content, and communicate with servers. It runs in a browser-managed sandbox with web APIs and security boundaries rather than unrestricted access to the user's system.
83. Why is Node.js able to run JavaScript on servers?
   **Answer:** Node.js embeds the V8 JavaScript engine outside the browser and provides APIs for files, networking, processes, and other server tasks. Its event-driven runtime is useful for I/O-heavy services; applications still need to handle errors, security, and CPU-intensive work appropriately.
